# 2027.2.11–2.21 · WF冬 × 纹别流冰 × 北海道

7人（北京 3 / 武汉 2 / 杭州 2）全程同行的可交互行程页。单文件、零依赖、可离线打开。

**线上**：<https://peipei707.github.io/hokkaido-2027/>

## 页面里能做什么

- **三张插画卡选线**：A 层云峡冰瀑 / B 知床流冰漫步 / C 札幌大本营，卡上直接写着换床次数、体力、道内花费。7 人全程一起，所以只选一条；顶部有常驻的路线切换条。
- **预算计算器**：住宿按 **2+2+2+1** 开房（三间双人房 + 一间单人房，北京 3 人 = 2+1），同住算半间、独住算单间全额，差价不摊给别人。可切机票口径（北京/武汉/杭州）、档位、房型、汇率，以及 ANA 访日外国人优惠运赁、纹别蟹会席、宅急便三个可选项；7 人合计 = 6 位同住 + 1 位独住、三地机票相加。
- **预订时间线**可勾选，状态存在浏览器本机；已进入窗口的日期标橙点。装备清单同理。
- **可点的路线地图**：手绘北海道轮廓 + 当前路线的站点连线，橙色虚线是 2/15 唯一那班飞机（羽田 10:35 → 纹别 12:20）。点地图上任一站点，下面的时间轴就展开那天；反过来展开某天，地图上的站点也会亮起。走 B 案时还会画出**钏网线**（网走→钏路全线约 3 小时 22 分，行程里只坐最北 50 分钟）。
- **逐日一行**：日期 · 图标 · 地点 · 一句话，点开才是细节，里面写了 7 人规模特有的坑（限定名额要凑齐 7 份、巴士座位一次订满）。

## 骨架

2/10 武汉 2 人先到杭州 → 2/11 东京汇合 → 2/12 搬入 → 2/13–14 幕张 WF（双日开催）→ **2/15 飞纹别 · 日落破冰航（羽田⇄纹别每天只有 ANA375 一班）** → 2/16–20 北海道（按所选路线）→ 2/21 新千岁分手。

三版差异：**A 道央经典**（层云峡冰瀑祭 + 旭山企鹅散步 + 小樽，换床4次）／**B 道东狂野**（知床流冰漫步 + 阿寒 + 丹顶鹤 + SL蒸汽，换床6次、依赖冬季限定班次最多）／**C 札幌大本营**（纹别后直达札幌5连泊只搬一次家，混合体力团最稳）。

## 两个改变了原计划的事实（2026年7月核）

1. **武汉无直飞日本航班**（东航武汉—成田、武汉—关西均已取消），所以武汉 2 人 2/10 先到杭州，2/11 与杭州组同班进东京；全团实际是「北京 3 人 + 华中华东 4 人」两条线。
2. **中日航线仍在大幅减班**，三大航对日本线免费退改已延至 2026/10/24 航季，2026/27 冬春航季计划要到 10 月下旬才明朗。因此出票拆成三步：先出 ANA375 羽田→纹别（全程唯一无替代的一段，7 张同一预订号）→ 10 月下旬复核班期 → 再出国际段，优先 ANA/JAL 实际承运。
